## Template Notes

**How to use this template:**

1. Copy this template when creating a new note
2. Update the frontmatter:
   - Replace `{{title}}` with your note title
   - Generate a unique `id` (e.g., `note-20260802-001`)
   - Set `type` to `note`
   - Add relevant `tags` using the hierarchy from SCHEMA.md
   - Fill in `related_notes` with connections to other notes
   - Add `category` classification

3. Keep the "Quick Overview" section for immediate context
4. Organize main content with clear sections
5. Add "Related Connections" section with wikilinks to cross-referenced content
6. Update "References & Sources" with your sources

**For AI Processing:**
- Add `context_hints` if there are special considerations
- Add `content_summary` for quick LLM retrieval
- Use `ai_instructions` if the note needs special handling
