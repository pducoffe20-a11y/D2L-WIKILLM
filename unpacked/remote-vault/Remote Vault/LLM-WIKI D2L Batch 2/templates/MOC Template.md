## Template Instructions

When creating a new MOC using this template:

1. **Replace all {{placeholders}}** with actual content
2. **Organize** by logical groupings (by type, by stage, by audience)
3. **Link** to actual notes using wikilink syntax `[[path/to/Note.md]]`
4. **Update metadata** frontmatter with:
   - Unique `id` (e.g., `moc-topic-001`)
   - Topic name in `title`
   - Relevant `tags` from SCHEMA.md hierarchy
   - List of `related_notes` linking to other MOCs
   - `topics` array for what this MOC covers
5. **Keep structure** with Core Topics, By Content Type, Related MOCs sections
6. **Maintain content status** table to show coverage percentage
7. **Review regularly** (suggested quarterly)

For complete frontmatter schema details, see: [[00-System/SCHEMA.md]]
