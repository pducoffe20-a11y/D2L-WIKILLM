## Optional Dataview enhancement

The core vault does not require Dataview. If installed, this query lists review items:

```dataview
TABLE type, status, confidence, review_after
FROM "01-Products" OR "02-Use-Cases" OR "10-Objections" OR "98-Needs-Review"
WHERE status != "verified"
SORT review_after ASC
```

If Dataview is installed, this query presents the reviewable engagement timeline without treating it as a system of record:

```dataview
TABLE engagement_date, engagement_kind, engagement_party, status, confidence
FROM "13-Signals"
WHERE type = "engagement-event"
SORT engagement_date DESC
```
