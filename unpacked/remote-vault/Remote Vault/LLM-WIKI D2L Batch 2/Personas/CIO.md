# Chief Information Officer / VP of Information Technology

## Role context

**Demographics & titles:**
- Chief Information Officer
- VP of IT
- Director of Enterprise Systems

**Scope:** Enterprise infrastructure, data security, cloud architecture, CRM/AMS integrations, compliance

## Business drivers

**Primary objective:** Ensure high system uptime (99.99%), zero security breaches, seamless SSO/API integrations, and zero technical debt.

**Key performance indicators (KPIs):**
- System availability (99.99%+ SLA)
- API call latency
- Security assessment pass rate
- IT ticket volume

**Business pressures:**
- Evolving cybersecurity threats
- Strict compliance regulations (GDPR, FERPA, SOC2)
- Integration complexity with existing AMS/CRM systems

## Buying behavior

**Technical literacy:** High; deeply involved in architecture, vendor evaluation, and integration strategy

**Decision role:** Technical Gatekeeper / Approver

**Critical capabilities evaluation:**
- LTI 1.3 / 1.1 certification
- 1EdTech Caliper analytics
- OneRoster
- REST APIs
- SAML/SSO integration

**Key objections & concerns:**
- Does it meet SOC2 Type II standards?
- How hard is it to integrate with our custom CRM/AMS?
- What is the vendor's disaster recovery SLA?

## Discovery questions

- How many hours does your IT team spend maintaining custom integrations or security patches for your current learning stack?
- What compliance certifications and audit standards are non-negotiable for your organization?
- How does your current AMS/CRM integrate with learning systems, and what gaps exist?

## D2L proof points

**Value propositions:**
- Fully managed AWS cloud platform with 99.99% uptime SLA
- 1EdTech certified across LTI, Caliper Metrics, and OneRoster

**Critical certifications:**
- SOC2 Type II compliance
- GDPR and FERPA data handling
- 99.99% availability guarantee with redundancy

**Integration capabilities:**
- Native LTI 1.3 support for seamless third-party integrations
- REST API for custom development
- Pre-built connectors for major AMS/CRM systems (Salesforce, Impexium, Personify, Higher Logic)
- SAML 2.0 for SSO federation

## Key messaging

*D2L's managed cloud infrastructure eliminates the security and infrastructure burden of on-premise or open-source solutions. Industry-leading certifications and 1EdTech compliance ensure seamless integrations with your existing systems.*
