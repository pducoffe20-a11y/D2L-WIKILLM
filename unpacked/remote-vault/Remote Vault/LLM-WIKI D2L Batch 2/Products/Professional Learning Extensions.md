# Professional Learning Extensions

## My CPD Records

My CPD Records lets users define professional-development targets by category and create records that count toward those targets. The current source also describes connections with Manager Dashboard and Brightspace Awards.

**Useful when the buyer says:**

- Professionals must track learning completed inside and outside formal courses.
- Managers or mentors need visibility into targets and progress.
- Members need one place to record development activity against annual requirements.

**Boundary:** The current page identifies general availability, but intended market fit varies. Confirm the buyer segment and proposed configuration rather than assuming universal fit.

Source: [My CPD Records overview](https://desire2learn.atlassian.net/wiki/spaces/DKR/pages/4428103784/My+CPD+Records+-+Overview), updated 2025-12-09.

## Profession Path

Profession Path supports a four-point self-assessment against a competency or professional-standards framework, learning recommendations, a learner-created plan and exportable engagement data.

**Useful when the buyer says:**

- Members need to benchmark themselves against a professional framework.
- The organization wants to guide development without building a full LXP.
- Learning recommendations should connect identified gaps to development options.

**Explicit boundaries:**

- Limited availability and controlled rollout.
- Initially focused on association use cases.
- English only in the current source.
- It is not an LXP.
- It does not automatically mark Brightspace course completion; learners manually mark recommendations complete.

Source: [Profession Path overview](https://desire2learn.atlassian.net/wiki/spaces/DKR/pages/4675994246/Profession+Path+-+Overview), updated 2026-03-16.

## Discovery split

- If the buyer already knows the required credits, hours or categories and mainly needs recording and progress tracking, explore **My CPD Records**.
- If the buyer starts with a competency framework and wants self-assessment, recommendations and a plan, explore **Profession Path**.
- If the buyer needs formal outcome aggregation across courses or programs, explore [[Achievement Plus Public Capabilities]] and the current internal Achievement+ source.
