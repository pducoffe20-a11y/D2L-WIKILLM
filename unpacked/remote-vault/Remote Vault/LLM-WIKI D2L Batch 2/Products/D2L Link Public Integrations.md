# D2L Link Public Integrations

The public page positions D2L Link as a way to connect Brightspace with an existing technology stack, automate data movement and reduce manual entry.

## Integration categories

- CRM
- HR systems
- Association management systems
- User and identity platforms
- Automated data delivery and storage

## Publicly listed examples

- CRM: Salesforce, HubSpot, Microsoft Dynamics 365, NetSuite and Oracle applications.
- HR: ADP Workforce Now, BambooHR, Dayforce, SAP SuccessFactors and Workday.
- AMS: iMIS, re:Members and NimbleAMS.
- Identity: Google Workspace, JumpCloud, Okta and Microsoft Entra ID.
- Data delivery: Amazon S3, Box, Dropbox, Google Cloud Storage, Google Drive, Microsoft OneDrive, Microsoft SharePoint and SFTP/FTP.

## Delivery model

The page distinguishes standard integrations, extended integrations and light or fully custom workflows built and maintained by D2L experts. It also describes sharing user, course, enrollment and other data with Brightspace.

## Boundaries

- A logo or list entry does not establish that every workflow, object or direction is supported.
- Standard, extended and custom options may differ in scope; verify the current page and solution design.
- Do not convert “hours versus months” marketing language into a customer timeline commitment.
