# Start with Their Needs, Not Our Offering

When pitching to associations, anchor conversations on what you already know about your target:

1. **If you know their main goal** -> Start with **[[Business Outcomes]]**
   - Increase member engagement and retention
   - Boost productivity
   - Generate non-dues revenue
2. **If you only know their role** -> Start with **[[Personas]]**
   - Board Member / Executive ([[Executive Erin]])
   - Membership Manager ([[Membership Manager Mo]])
   - Member ([[Member Melanie]])
3. **If you only know a need** -> Start with **[[Use Cases]]**
   - High-Impact Learning Experiences
   - Certifications and Credentialing
   - Content Creation & Process Improvement
   - Data-Driven Insights & Monetize Learning
4. **If you want to know a required capability** -> Start with **[[Products]]**
   - D2L for Associations Package
   - Creator+
   - Performance+
   - D2L Link or D2L Lumi
   - D2L Course Merchant
