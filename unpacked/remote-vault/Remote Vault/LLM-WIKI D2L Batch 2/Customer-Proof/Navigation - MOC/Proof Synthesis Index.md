# Proof Synthesis Index

## Full tag-based navigation

For a complete, tag-generated browse of all 143 customer stories in this folder — by industry, use case, outcome, and product, plus a list of customers with multiple stories on file — use [[Customer Story Navigator]].

## Verified routing source

[Quotes, Stories, and References](https://desire2learn.atlassian.net/wiki/spaces/LXC/pages/4306501770/Quotes+Stories+and+References), updated 2026-07-15, is the current Rovo source read for customer quotes and stories organized by vertical.

## Proof card format

Before external use, record the customer, exact wording or reported outcome, named product if present, source link, source date, and permission status.

## Current proof rules

The Rovo page includes permission cautions for references. Its presence verifies a routing source; it does not make every quote public or authorize a reference call. Metrics, causality, ROI, timing and scale remain customer-scoped.

## Published proof cards

[[Curated Proof Point Cards]] is the seller-ready entry point for individually read public stories. It currently covers growth, consolidation, administrative efficiency, onboarding scale, time to launch, professional learning, adoption and regulated training.

## Gaps to maintain

The curated cards are a controlled starting set, not a complete customer catalog or similarity engine. Product-specific proof, migration proof, K–12 coverage and additional “most similar customer” paths still require expansion from individually read records.
